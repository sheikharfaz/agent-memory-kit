# Code of conduct

This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

In short:

- Be respectful and assume good faith. Critique code and ideas, not people.
- No harassment, insults, or discriminatory language, in any project space —
  issues, pull requests, discussions, or anywhere you are representing it.
- Disagreement is welcome; make it specific and evidence-based. This
  project's own rule is "measured, not asserted", and that applies to
  arguments as much as to benchmarks.

## Reporting

Open an issue, or if the matter is sensitive, contact the maintainer through
their GitHub profile. Reports are handled privately. The maintainer may
remove content or restrict participation for behaviour that breaks this
code.
